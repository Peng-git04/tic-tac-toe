# Tic Tac Toe

A simple Tic Tac Toe game built with Vue 3 and TypeScript.

## 🎮 Live Demo

[Play here](https://Peng-git04.github.io/tic-tac-toe/)

## 🛠️ Tech Stack

- Vue 3
- TypeScript
- Vite

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/Peng-git04/tic-tac-toe.git
cd tic-tac-toe
npm install
npm run dev
```

## 📦 Build & Deploy

Build for production:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```

## 🎯 Features

- Two player mode (X and O)
- Win detection
- Draw detection
- Reset game button
